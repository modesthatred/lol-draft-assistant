## Жалобы пользователя (разбор по пунктам)

### 1. Окно настроек (СДЕЛАНО в 1.3)
- Жалоба: «сделай окно шире и ниже — в 2 раза шире и в 2 раза ниже», «кнопки „Сохранить/Отмена“ должны быть всегда видны и не ломаться».
- Сделано: тело настроек прокручиваемое (Canvas + скроллбар + колёсико), кнопки «Сохранить/Отмена» прибиты к низу вне прокрутки, окно 820x720 ресайзится.

### 2. Состояние ожидания драфта (СДЕЛАНО 1.2.10)
- Жалоба: при ожидании драфта оверлей показывал красную «ошибка» и молча исчезал.
- Решение: `ready_message()` классифицирует waiting-состояния как спокойные; заголовок «готов: жду драфт» / «клиент ещё созревает»; убран автоскрытие после старта; убрано дублирование в body.

### 3. Оверлей целиком за краем экрана (СДЕЛАНО 1.2.9)
- Жалоба: сохранённая позиция уводила окно за пределы экрана.
- Решение: `clamp_rect`, `_clamp_on_screen`, `_desktop`, репозишн в `show()`.

### 4. Кэширование данных (СДЕЛАНО 1.3)
- Жалоба: каждый запуск заново перечитывает/перекачивает данные.
- Решение: персональные данные (u.gg) и мета-предметы (lolalytics) перечитываются не чаще раза в 12 ч (`personal_ttl_hours`); общая мета — по патчу.

### 5. Роль/лейн в скоринге (СДЕЛАНО 1.3)
- Жалоба: Шен в роли саппорта получал советы как от Ясуо ADC; предметы брались не по линии.
- Решение: билд предметов тянется по МОЕЙ роли из драфта (`draft.my_role`), линия lolalytics уточняет мета по линии; личные проигрыши считаются по ролям.

### 6. i18n RU/EN (ОТКРЫТО)
- Жалоба: интерфейс только на русском; нужен выбор языка.
- Нужно: словарь строк, переключатель в настройках, значения по умолчанию RU.

### 7. Публикация релиза (СДЕЛАНО)
- Жалоба: релиз не появляется на GitHub, приходится вручную прикреплять exe пять раз.
- Решение: токен из `git credential manager` + GitHub Releases API; релиз и ассет публикуются автоматически.

### 8. Порядок в проекте (СДЕЛАНО)
- Жалоба: файлы вне папки проекта.
- Проверено: лишних файлов вне `D:\Apps\Lol helper\Default Project\lol-draft-assistant` нет.

## Возможности 1.3 (добавлены)

### Персональные советы (u.gg)
- До трёх аккаунтов (мейн + смурфы на других серверах) в настройках: сервер, ник, тег.
- Кнопка ✓ проверяет, что профиль существует; клик по нику открывает профиль в браузере.
- В оверлее две линии предметов: мета по драфту + «моя история» (предметы из моих победных игр).
- Две колонки банов: общий совет по мете + «мои проигрыши» (с кем лично игрок теряет, по роли).

### Мета-предметы lolalytics (второй источник)
- Отдельный парсер: `https://lolalytics.com/lol/{champ}/build/?lane={lane}` — секции Starting/Core по линии, патч, тир.
- В оверлее отдельная линия «мета по линии».

### Источники и VPN
- Настройка «Источники»: op.gg / lolalytics / u.gg включаются/выключаются.
- Поле прокси/VPN `http://127.0.0.1:10808` (порт бывает 10809) + кнопка «Проверить», которая показывает, какой сайт работает напрямую, а какой — только через VPN.
